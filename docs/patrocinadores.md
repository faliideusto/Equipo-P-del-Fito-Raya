- Aerointer: https://www.aerointer.es/la-empresa-aerointer/

- Pádel Game Xerez: perfil de reservas https://playtomic.com/clubs/padel-game-xerez. Se usa este enlace en lugar de la web antigua que no respondió durante la comprobación.

Las tarjetas enlazan a webs de las empresas o a sus páginas de carta/reservas, abriendo una pestaña nueva. Se editan en `src/data/sponsors.ts`.
